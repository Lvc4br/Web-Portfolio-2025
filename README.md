# Web Portfolio 2025 — Protótipo de Estudo

> **Status:** protótipo histórico de portfólio. Não é a versão principal atual.

Este repositório preserva uma versão anterior de um site pessoal construído com HTML, CSS e JavaScript nativo. O propósito é registrar a evolução do projeto e manter os arquivos de uma etapa anterior, não substituir o portfólio atual.

## Arquitetura e estrutura

```text
Web-Portfolio-2025/
├── index.html           # página inicial
├── project.html         # página de projetos
├── CSS/                 # folhas de estilo
├── JS/
│   ├── app.js           # interações
│   └── particles.js     # efeito de partículas
├── img/                 # imagens e recursos visuais
└── Docs/
    └── certificados/    # imagens de certificados
```

A aplicação é estática e executada no navegador. Não há framework, backend ou dependências npm documentados. A árvore acima descreve as áreas principais; consulte os arquivos para confirmar caminhos e imports antes de alterar o projeto.

## Executar

Abra `index.html` em um navegador ou sirva a raiz do repositório por um servidor HTTP estático. Não é necessário processo de build.

## Estado e limitações

- Protótipo de estudo, não mantido como portfólio oficial.
- Não há testes automatizados, lint ou pipeline de build documentados.
- Não se presume que todos os links, recursos ou layouts antigos continuem funcionais.
- Os certificados e as imagens são recursos estáticos do protótipo.
